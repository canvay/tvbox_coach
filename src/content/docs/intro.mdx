TVBox 是一款运行在电视盒子 / 电视 / 手机上的开源播放器外壳，它本身**不提供任何影视内容**，
而是通过加载「接口配置」来组织内容源。

## 它是如何工作的

- **播放内核**：基于 ExoPlayer / IJKPlayer，支持 HTTP、HLS（m3u8）、DASH、MP4 等常见流媒体格式
- **工作方式**：「播放器壳 + JSON 配置」的插件化形态——TVBox 是遥控器，接口是电池，没有接口它什么都做不了
- **生态现状**：原作者 takagen99 的 TVBoxOSC 已停更，现在活跃的都是社区分支

## 基本概念

| 概念 | 说明 |
| --- | --- |
| 配置（接口） | 一段 JSON 或一个 JSON 地址，定义了站点列表、直播源、解析逻辑等，是 TVBox 的「灵魂」 |
| 站点（sites） | 内容来源入口，一个接口里通常包含多个站点 |
| 直播源（lives） | 电视台直播频道的地址列表 |
| Spider（爬虫） | 部分站点需要的 jar 包，用于解析网页内容，一般随接口自动下发 |

## 主要分支 / 客户端

TVBoxOSC 的配置格式仍是事实标准，但不同分支对配置格式的兼容度有差异：

| 客户端 | 说明 |
| --- | --- |
| 影视仓（FongMi 系） | 国内最流行的分支之一，支持爬虫 spider、直播、多 jar |
| OK影视（FongMi） | FongMi 另一发行版，功能与影视仓相近 |
| TVBoxOSC（takagen99） | 最早的公开分支，已停更 |
| FreeBox | TVBox 电脑版，跨平台生态扩展 |

## 合规提示

> ⚠️ TVBox 本身是中性的播放器，但其主流用法（第三方采集源、爬虫、解析）绝大多数指向
> 未授权的盗版资源，在国内有明确法律风险。自建相关服务时请只聚合公开、合法授权的片源信息，
> 不存储 / 不分发视频文件，并定位为个人学习与自用。

装好客户端后，继续阅读 [TVBox 安装](/tvbox_coach/tutorials/install/)。
