## 获取安装包

在可信渠道获取 TVBox / 影视仓 / OK 影视等客户端的安装包（apk），常用客户端可从
[网盘发布地址](https://pan.quark.cn/s/f0a65d6cad33)获取。

> ⚠️ 注意：**不要相信任何「付费代装」「收费会员」宣传**，TVBox 本身是免费开源的。

## 安装步骤

1. 用 U 盘把安装包拷贝到电视盒子，或通过局域网共享、当贝市场等方式安装。
2. 首次打开时若提示「禁止安装」，到系统设置里允许「安装未知来源应用」。
3. 打开应用，进入首页即可开始配置接口。

## 装好后的基本操作

- **搜索**：首页顶部搜索，可跨站点搜索影片。
- **历史 / 收藏**：播放过的影片会进入历史，长按可收藏。
- **切换站点**：播放卡顿时，返回列表换一个同名片源即可。

装好之后，下一步是给 TVBox 填入接口配置，看[配置教程](/tvbox_coach/tutorials/config-setup/)。
