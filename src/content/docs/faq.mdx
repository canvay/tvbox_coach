## 1. 配置加载失败 / 一直转圈

- 先用电脑浏览器打开接口地址，确认还能访问；
- 网络问题：盒子走的网络可能无法访问接口所在服务器，试试手机热点对比；
- 接口失效就换接口，参考 [接口配置教程](/tutorials/config-setup) 的排查步骤。

## 2. 站点列表为空或影片刷不出来

- 用 [接口解析工具](/tools/parse) 粘贴配置内容，看 `sites` 数量是否正常；
- 站点 type=3 的站点依赖 spider jar，jar 失效则整片失效，换接口；
- 单个站点挂了不一定是接口问题，切换其他站点验证。

## 3. 播放卡顿 / 频繁缓冲

- 同一部片往往有多个片源，播放页切换「线路 / 片源」重试；
- 盒子性能弱：设置里把解码器切换为「系统播放器」或「软解」对比效果；
- 网络高峰期卡顿属正常，错峰观看或换接口。

## 4. 直播没台 / 全部失效

- 直播源时效性极强，先确认直播源地址是否还在更新；
- 用 [接口测活](/tools/check) 检查直播源里的频道地址；
- 运营商 IPTV 源仅限内网使用，公网环境访问不到是正常现象。

## 5. 应用闪退 / 无法安装

- 老盒子注意安卓版本，选适配低版本的老版本客户端；
- 安装包损坏：重新下载并校验；
- 内存不足：清理后台应用后再试。

## 6. 安全底线

- **TVBox 本体和所有正规接口都是免费的**，遇到收费的请直接拉黑；
- 不安装来源不明的「破解版」「会员版」；
- 本站所有内容仅供学习交流，请遵守当地法律法规。
