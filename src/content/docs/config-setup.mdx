「接口」是 TVBox 的配置入口，格式上就是一段 JSON。本文讲清楚它长什么样、里面每个字段是什么意思、怎么填、坏了怎么修。

## 一、配置长什么样

一个典型的配置示例：

```json
{
  "spider": "./jar/spider.jar;md5;xxxx",
  "wallpaper": "https://example.tv/wallpaper.jpg",
  "sites": [
    { "key": "site_a", "name": "站点A", "type": 3, "api": "csp_SiteA" }
  ],
  "lives": [
    { "name": "直播", "type": 0, "url": "https://example.tv/live.txt" }
  ],
  "parses": [
    { "name": "Json并发", "type": 2, "url": "Serial" }
  ],
  "flags": ["youku", "qq", "iqiyi", "m3u8"]
}
```

各字段的含义：

| 字段 | 作用 |
| --- | --- |
| `spider` | 爬虫 jar 包地址，type=3 站点靠它解析网页内容，随配置自动下载 |
| `wallpaper` | 应用背景壁纸图片地址 |
| `sites` | 站点列表，影视内容的来源入口（见下文） |
| `lives` | 直播源列表，指向一份「频道名 + 播放地址」清单 |
| `parses` | 解析器列表，用于还原加密的播放页（见下文） |
| `flags` | 平台标识（优酷、爱奇艺等），配合解析器嗅探使用 |

## 二、站点类型（sites 的 type）

`sites` 里每个站点都有一个 `type`，决定了 TVBox 怎么从它取数据：

| type | 名称 | 说明 |
| --- | --- | --- |
| 0 | XML 采集 | 苹果CMS 传统 XML 接口（`api.php/provide/vod/at/xml`），老站常用 |
| 1 | JSON 采集 | 苹果CMS V10 JSON 接口（`api.php/provide/vod`），**最通用**，支持筛选参数 |
| 3 | 爬虫源 | `api` 指向 jar 里的 `csp_XXX` 类名或 `.js` 脚本，灵活但依赖 spider jar |
| 4 | JSON 扩展 | 指向自建的、实现 TVBox spider 协议的 HTTP API，较少用 |

简单记：**type 0/1 是「现成的采集站」**，直接消费标准接口；**type 3/4 是「定制的爬虫」**，需要 jar 或脚本配合。

`sites` 里还有几个常见的开关字段：

- `searchable`：是否参与全局搜索
- `quickSearch`：是否支持快速搜索
- `filterable`：是否支持分类筛选
- `ext`：传给爬虫的自定义参数（如子配置地址）

## 三、进阶：数据接口协议

type 0/1 源消费的是**苹果CMS V10 采集接口**，想自建 API 的话必须兼容这几个端点：

```text
GET /api.php/provide/vod?ac=list                 # 分类 + 分页列表
GET /api.php/provide/vod?ac=detail&wd=关键词      # 搜索
GET /api.php/provide/vod?ac=detail&ids=1         # 详情，含播放地址
```

响应里的关键字段：

- `vod_play_url`：播放地址串，格式 `第1集$https://xxx.m3u8#第2集$https://xxx.m3u8`，多播放组用 `$$$` 分隔
- `vod_play_from`：各播放组标识，与 `vod_play_url` 用 `$$$` 一一对应
- `vod_remarks`：备注（如「更新至xx集」）、`vod_class`：分类

> 注意各客户端对字段空缺、编码、HTML 内容的容错差异不同，自建接口建议用 1~2 个主流客户端实测。

## 四、解析器（parses）

有些片源地址被平台加密藏在网页播放页里，需要「解析」接口还原出真实的 m3u8 地址。`parses` 里同样用 `type` 区分：

- **type 0**：URL 解析，直接把播放页地址拼给解析接口
- **type 1**：JSON 解析，请求后从返回的 JSON 里取 url
- **type 2**：聚合解析（Json 并发 / 轮询），同时跑多个解析接口取最快的
- **type 3/4**：嗅探，用 webview 加载播放页抓取真实跳转地址

日常使用不用管它——配置里已经写好了，了解原理有助于看懂配置、排查「有片名但播不了」的问题。

## 五、怎么填入

1. 复制接口地址（以 `.json` 结尾或返回 JSON 的链接均可）。
2. TVBox → 设置 → 配置地址 → 粘贴 → 确定。
3. 返回首页等待加载。第一次加载会下载 spider jar，稍慢属于正常。

**懒人技巧**：应用设置里一般有「扫码」入口，手机端打开接口页面扫码即可，免去遥控器打字。

## 六、配置失效的排查步骤

1. **电脑浏览器打开接口地址**，看是否还能显示 JSON 内容（而不是 404 / 空白）。
2. 内容还在但 TVBox 加载失败 → 可能是 spider jar 失效，换个接口试试。
3. 用本站 [接口解析与格式化](/tvbox_coach/tools/parse) 工具粘贴配置内容，检查 `sites` 是否为空、JSON 是否合法。
4. 单个站点刷不出内容不一定是接口问题：先切到其他站点对比验证；type=3 站点集体失效大概率是 jar 挂了。
5. 接口彻底失效 → 到接口分享社区找新接口，或自己动手改造（进阶）。

> 💡 接口是社区自发维护的，**失效是常态**，多备几个地址轮换是使用 TVBox 的基本修养。

## 七、安全提醒

- 不要填入来源不明的接口：配置可以指定任意 spider jar，存在风险。
- 不使用任何「收费接口」「会员接口」——官方本体永远是免费的。
